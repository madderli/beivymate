# BeivyMate

BeIvyMate is an AI Worker Agent.

The system supports role-based AI agents, such as:

- Tester Agent
- Developer Agent
- PM Agent

The first MVP focuses on the Tester Agent.

## MVP

The Tester Agent MVP supports:

1. Requirement Understanding
2. Test Analysis
3. Test Design
4. Test Execution
5. Test Report

## Technology

- Python
- Pydantic
- Pytest
